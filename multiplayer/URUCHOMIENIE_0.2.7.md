# Instalacja ASHEN v0.2.7
1. Wyeksportuj zapisy JSON najważniejszych postaci z gry.
2. Wgraj zmienione pliki do repozytorium ASHEN na GitHub.
3. Ctrl + F5 w obu przeglądarkach.
4. Zaloguj się na każdym koncie osobno, wybierz właściwy profil, kliknij „Wyślij aktualną postać” **jeden raz** (nowe powiązanie chroni przed pomyleniem kont).
5. Obserwuj status synchronizacji w sekcji PvP, przeprowadź wyprawę, sprawdź po chwili `ashen_cloud_saves`.
6. Opcjonalnie: projekt Supabase **ASHEN** → SQL Editor → uruchom `004_message_limits.sql`, który ograniczy spam prywatnych wiadomości. Poprzednich SQL nie uruchamiaj ponownie.
7. Wyloguj się z jednego konta, zaloguj się na drugie i sprawdź, że to konto wymaga przypisania własnej postaci.
**Nie uruchamiaj żadnego SQL w ALLADYN.** Nie ma tu pełnej ochrony przed oszustwami ani bezpiecznego łączenia zmian z wielu urządzeń.
