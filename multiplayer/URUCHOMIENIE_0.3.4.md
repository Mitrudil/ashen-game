# Instalacja ASHEN v0.3.4

1. Podmień na GitHubie: `index.html`, `css/style.css`, `js/game.js`, `js/online.js`, `js/players.js`.
2. Uruchom w SQL Editor projektu ASHEN plik `multiplayer/supabase/012_mail_and_profiles.sql` (po wcześniej zainstalowanej wersji 0.3.3 / pliku SQL 011).
3. Wciśnij Ctrl + F5 na stronie gry.
4. Otwórz Odebrane, prywatną wiadomość i wypróbuj „Odpowiedz”.
5. Zaznacz kilka wiadomości i wypróbuj „Oznacz jako przeczytane” / „Usuń zaznaczone”.
6. Otwórz profil gracza z listy członków klanu / PvP / wiadomości — pojawi się oddzielne okno nad grą.
7. Sprawdź, że atak PvP pokazuje powiadomienie w Odebranych u obu graczy, bez duplikatu w Wysłanych.

**Ważne:** Nie uruchamiaj skryptu w Supabase ALLADYN. Nie uruchamiaj ponownie wcześniejszych instalacyjnych SQL.
