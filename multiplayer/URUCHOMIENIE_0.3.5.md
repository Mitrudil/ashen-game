# ASHEN v0.3.5 — instrukcja: indywidualny łup ekspedycji

**Aktualizacja z v0.3.4:**
1. Rozpakuj paczkę `ASHEN_v0.3.5_AKTUALIZACJA_GITHUB.zip` i wgraj zawartość do katalogu głównego GitHub Pages z grą.
2. Uruchom tylko `multiplayer/supabase/013_individual_boss_rewards.sql` w SQL Editor projektu **ASHEN**.
3. Odśwież grę (Ctrl + F5), wejdź w Ekspedycje i rozegraj nową zwycięską wyprawę.
4. Odbierz nagrodę w panelu „Moje nagrody z ekspedycji”.

Otrzymane przedmioty trafiają do istniejącego Ekwipunku. Odbieraj tylko na profilu przypisanym do danego konta online.

**Uwaga:** skrypt nie dodaje nagród do historycznych walk, nie zmienia parametrów bossów ani zapisów postaci.

Wersja prototypowa: zapisy postaci są lokalne z synchronizacją w chmurze; przed zmianą urządzenia poczekaj na synchronizację konta.
